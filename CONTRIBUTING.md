# Contributing

Thanks for your interest in contributing to this project. A few guidelines to get started:

- Fork the repository and open a pull request with descriptive title and tests for changes.
- Keep changes small and focused; open issues for larger discussions.
- Follow existing code style. Run `flutter analyze` in `parent_app` and `python -m flake8` (if available) for backend checks.
- Before committing, ensure no secrets (API keys, database files) are included.

Reporting security issues
- For sensitive disclosures (vulnerabilities, secrets), please contact the repository owner directly rather than opening a public issue.
